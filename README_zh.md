## 为什么写这本书

每天都有新的AI模型、新的工具、新的"你的工作要被取代了"的标题。噪音震耳欲聋，焦虑真实存在。

但市面上关于"AI和未来"的内容几乎都逃不出三类：

1. **技术手册** — 怎么用AI写代码（你不是开发者就没用）
2. **效率技巧** — 怎么用AI更快地写邮件（有用但太浅）
3. **贩卖焦虑** — "AI会抢走你的工作！"（对一部分人来说是真的，但没给出路）

**这本书不一样。** 它不是教你怎么用AI，而是关于**在AI能做一切的时代，怎么做一个"人"**。

写给谁：
- 担心下个季度被裁的公司上班族
- 想保持竞争力但没有技术团队的小老板
- 看着AI用低价内容淹没市场的自由职业者
- 正在选专业、选职业方向的学生
- 行业刚被AI颠覆的中年转型者
- 只是想跟上时代、不想被抛弃的普通人

**不需要会编程。没有噱头。不制造恐慌。**

## 核心命题

> AI时代的终极竞争力，不在于"比AI做得更好"，而在于"做AI不能做或不该做的事"。

AI没有身体。它没有痛过。它不知道失去一个人是什么感觉，不知道抱着孩子是什么感觉，不知道在雨里走是什么感觉，不知道做了一个让你彻夜难眠的决定是什么感觉。这些不是bug——这些是AI的边界。而它们恰好是你存在的地方。

这本书帮你找到那条线，然后让你的人生站在正确的一边。

## 正文与附录：怎么读这本书

正文讲的是**怎么想**，附录给的是**用什么**。两者过期的速度完全不同，这是有意的。

| | 正文 | 附录 |
|---|------|------|
| 回答 | "这件事我该怎么想？" | "现在该用哪个工具、什么价？" |
| 过期 | 慢——是论证，不是产品 | 快——按月，有时按周 |
| 免费 | 第一、二篇免费 | 付费层 |

所以本书**不主张**自己的工具矩阵是权威的。它做不到，而 ch21 的存在就是把这件事说清楚：它教你
自己判断一个工具，这样当附录 A 过期时——它一定会过期——你不至于只能等别人来更新。
**附录是便利，判断力才是产品。**

## 为什么是"活书"

AI每周都在变。纸质书还没印出来就过时了。

这是一份**活体文档**——像软件一样版本控制，像新闻编辑室一样持续更新。每章都有"最后更新"时间戳和模型版本号。工具下架了，我们划掉。新模型发布了，我们测试。法律变了，我们标注。

你买的不是一本静态PDF。你订阅的是一个**生存情报系统**。

## 创作方式

本书由**人类与AI协作完成**，全程公开：

```
信息源（RSS / X / ArXiv / Product Hunt）
        ↓
    AI摘要（Perplexity / NotebookLM）
        ↓
    DeepSeek 撰写初稿
        ↓
    Reasonix Agent 管理文件与构建
        ↓
    人类编辑（我）审校、核查事实、做判断
        ↓
    GitHub Actions 开PR → 我合并 → 构建并交付
```

每章末尾标注：

```markdown
---
📅 最后更新：2026-09-30
🤖 辅助模型：DeepSeek + Reasonix
✍️  审校：人类（就是我）
⚠️ 关键事实请自行核实——AI迭代很快，我尽力了。
---
```

**透明是特性，不是缺陷。**

## 仓库结构

```
chapters/en/          书稿正文。唯一源文件——译本由此派生
  README.md           章节索引 + 各章进度状态
appendix/             月度更新的工具矩阵与提示词库
templates/            章节模板（含元信息与必备页脚）
scripts/              本地工具：校验、发布、SSH 配置、gh 引导安装
WORKFLOW.md           一章如何写成、如何发布
CHANGELOG.md          变更记录，按日期
```

**想动笔就从这里开始：** [WORKFLOW.md](WORKFLOW.md)。

简要流程：

```bash
cp templates/chapter-template.md chapters/en/ch02-your-slug.md
# ...开始写...
./scripts/check-chapter.sh  chapters/en/ch02-your-slug.md   # 校验
./scripts/publish-chapter.sh chapters/en/ch02-your-slug.md  # 开分支 → 提交 → 推送 → 开 PR
```

一章一个分支、一个 PR，自行合并。正文以英文为先，中文译本后续跟进。

发现死链？工具下架了？事实错误？我遗漏了什么视角？
